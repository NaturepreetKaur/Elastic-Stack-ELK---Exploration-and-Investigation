# Elastic Stack Installation
## Overview
This document records the installation and initial setup of the Elastic Stack for a cybersecurity lab environment.The Elastic Stack consists of several components that work together to collect, process, store, search, and visualize data.
## Elastic Stack Components

### Elasticsearch

Elasticsearch is the core search and data storage engine. It stores and indexes data so that it can be searched and analyzed efficiently.

### Kibana

Kibana is the web-based interface used to search, analyze, and visualize data stored in Elasticsearch.

### Logstash

Logstash is a data processing pipeline that can collect, transform, and forward data to Elasticsearch.

### Elastic Agent

Elastic Agent is used to collect telemetry and logs from systems and send the data to the Elastic Stack.
## Environment

- Operating System: Ubuntu
- Virtualization: VMware
- Purpose: Security monitoring and log analysis
## Prerequisites

- Ubuntu Linux
- Internet connectivity
- Sudo privileges
- Sufficient system resources
